# 🎓 EduBridge Secure Document Vault

A secure, multi-tenant document management system designed for educational institutions. This platform ensures that student and faculty documents are stored securely and separately using advanced cloud partitioning.

## 🛠️ Tech Stack

- **Backend**: Spring Boot 3, Spring Security (OAuth2 / JWT)
- **Frontend**: React, TypeScript, Vite
- **Storage**: AWS S3 (SDK v2)
- **Infrastructure**: Docker, PostgreSQL, Redis, RabbitMQ

## 🚀 Key Features

- **Multi-tenant Storage**: User-isolated file storage in AWS S3.
- **Stateless Authentication**: Robust security using JWT and OAuth2.
- **Modern UI**: Responsive React interface with glassmorphism design.

## ▶️ Quick Start

### Backend

```bash
./mvnw spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
